下载后，三步开始使用
  1. 把 Markdown 上传给 Agent，或放进它能读取的工作目录。
  2. 明确要求它先读取文件，并说明本次文种、读者和额外要求。
  3. 让它列出匹配的规则，再核对实际输出。

文件内附可复制的开场指令。导出是静态快照，习惯更新后需重新导出；不会自动改变其他 Agent 的记忆。
